# 精简后台无用管理入口

## Goal
减少管理员后台中不常用、无必要的展示入口，让导航和系统配置更聚焦核心运营流程。

## Scope
- 从“系统配置”页面移除“最近失败代充”展示表格；不删除后端数据与接口。
- 移除左侧“浏览器池”导航和对应页面；不改浏览器池后端运行能力。
- 移除左侧“账单记录”导航和对应页面；不删除账单数据与后端接口。
- 清理前端因入口移除而不再需要的加载触发和页面状态引用，避免运行时访问不存在的元素。
- 不修改兑换、CDK、Session、银行卡池、任务管理、代理池等现有功能。

## Acceptance Criteria
- 后台导航不再显示“浏览器池”和“账单记录”。
- 系统配置页面不再显示“最近失败代充”表格。
- 前端脚本语法检查、项目测试和 `git diff --check` 通过。
- 后端接口、数据库表和已有账单/失败记录不做删除性改动。
